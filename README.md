# 赣风 · 可对话的数字展

把江西三条文化线做成可走、可问、可核验的数字展：**约束可审计 · 出处可核对**——冲突组合触发约束表规则；规则可展开；改锁在矩阵上回放。

本仓库参加全国大学生数字媒体科技作品及创意竞赛（CMIT）**第十四届（2026）指定命题「科技+创意，讲好中国故事」**（国际赛道口径：auditable constraints / checkable sources / on-device guide）。

- 离线一键运行：见 [运行环境.md](运行环境.md)（`sh scripts/package.sh` 生成 `release/赣风-离线版.zip`，Windows 双击 start.bat）。
- 出处登记：`src/data/sources.ts`（25 条，全部已直接打开页面核对；其中 2 条为二手资料，文内注明）；第三方许可：[THIRD_PARTY.md](THIRD_PARTY.md)。

> 事实性说明均绑定公开出处（审计面板可展开原文摘录）；核不到的条目标「待核 / 示例」。器型是程序模型、围屋平面是示意图，不是馆藏实物或实地测绘。

## 赛道对位

指定命题：科技+创意，讲好中国故事（2026）。一句话：用可审计的约束表讲赣鄱文化——内容准确、出处可核对，而不是提示词出图。

三条线五分钟够走完：

1. 瓷语 — 景德镇：选器型、釉色、朝代。宋代粉彩一类冲突会被改锁，并写明理由。展柜是程序釉面，引用条钉在旁边。
2. 阁序 — 滕王阁 / 《滕王阁序》：点落霞、孤鹜、秋水、飞阁。每一块画面绑定原句。
3. 客家 — 赣南围屋：门楼到禾坪、天井、祖堂、角楼。强调可走，方言词条钉在房间上。

## 开源思路 vs 原创

详见 OSS_VS_ORIGINAL.md。

- 借鉴：ComfyUI 式阶段可见的工作流图；博物馆展陈动线；轻量 three.js / 2.5D 场景。
- 原创：江西三条线内容包、约束控件与冲突改锁、场景内引用条、问展题库（拒绝无出处作答）、参观动线与视觉。
- 诚实声明：无付费 API，无 GPU。所谓生成是精选静帧 + 程序材质 + 可见管线（排队 → 风格锁定 → 出处绑定）。问展在浏览器里跑 BGE-small 检索小模型，答案只来自内容包。界面始终标明示例 / 生成中。

本项目不是 Dify 二次开发，不是 ChatGPT 皮肤。

## 本地运行

需要 Node.js 18 或更高。无需账号、无需 GPU。

在项目目录先安装依赖，再启动开发服务器。浏览器打开终端提示的地址（默认本机 5173 端口）。

快捷键：1 瓷语，2 阁序，3 客家，Esc 回门厅。右上角「声景」「讲解」默认关闭。讲解用浏览器 SpeechSynthesis，无云端、无 Key；关着时仍显示底部字幕。无网时中文字体回退系统宋体或黑体。构建用 package.json 里的 build 与 preview 脚本。许可为 MIT。

## 如何录 5 分钟视频

按这个顺序点，不要解说成聊天机器人。

0:00-0:40 门厅三扇门。展览看完就忘 vs 可对话可约束。点开开源边界。

0:40-2:10 瓷语。选明、梅瓶、青花，等管线走完，展开一条引用。再点宋与粉彩，让冲突改锁出现。问展点为什么宋代梅瓶不能锁成粉彩。

2:10-3:20 阁序。点落霞，原句高亮。再点孤鹜、渔舟。说明画面绑定原句，不是另写提示词。

3:20-4:20 客家。按沿动线走下一步，从门楼到祖堂，再点角楼。说明围屋不是土楼。改时辰看声景。

4:20-5:00 回到门厅或任一引用条。复盘创新：约束加出处。许可证 MIT。资料为示例。

过程图建议截这几屏（约 5 到 10 张 JPG）：门厅三门；瓷语约束面板（含合、勉强、冲突）；管线停在风格锁定；引用条展开；风格冲突改锁警告；阁序点落霞与诗文高亮；客家平面当前房间与方言词条；问展拒绝题库外问题。
