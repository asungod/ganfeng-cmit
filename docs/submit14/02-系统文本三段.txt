【作品简介】
赣风·可对话的数字展是一个可以离线运行的互动网页数字展，用三条参观线讲江西的文化故事：「瓷语」看景德镇瓷器的器型、釉色与年代；「阁序」把王勃《滕王阁序》的名句钉在夜景中的滕王阁上；「客家」走进赣南围屋，按时辰切换门楼、天井、祖堂与角楼。
作品的核心是一张可审计的约束表。访客点选或用自然语言提问后，系统用「合 / 勉 / 冲」三档判断这个组合能不能成立。例如「宋代粉彩」会被判为冲突（粉彩创烧于康熙晚期），并自动改锁为宋代影青，矩阵上会回放「冲突格 → 规则 → 改锁格」的全过程。
每条规则都可以在审计面板里展开：依据原文摘自故宫博物院、中国非物质文化遗产网、龙南市人民政府等公开页面，标有网址和访问日期；面板还提供「试一下」按钮，可现场复现命中、边界、例外三类案例。核不到出处的内容一律标「待核」。
「问展」在浏览器内用 BGE-small-zh 小模型检索展内题库，检索分数低于阈值的问题明确拒答，不接云端大模型，也不联网。

【创意来源】
文化类数字内容常见「张冠李戴」：宋代的瓶子画着清代才有的粉彩，诗句和不相干的景物拼在一起。观众很难自己判断真假，作者也很难证明自己没错。
本作品换一种讲法：让观众能看到故事为什么这样讲。做法是把文化知识写成约束表——年代与工艺、诗句与意象、空间与时辰——每条规则都能展开出处、现场验证。
选材来自江西：景德镇手工制瓷技艺是第一批国家级非物质文化遗产，《滕王阁序》是公有领域的千古名篇，赣南客家围屋营造技艺是国家级非遗。三条线分别对应史实约束、文本锚定和叙事约定三类规则，并在界面上明确区分「已核出处」「本展设计约定」和「待核」。
技术上用三维展柜、矩阵回放和浏览器端小模型检索；评审可以现场核对内容、过程与出处。

【运行环境】
运行方式：解压「赣风-离线版.zip」，Windows 10/11 双击 start.bat；macOS 双击 start.command（首次如被拦截，右键→打开）；Linux 运行 sh start.sh。浏览器会自动打开 http://127.0.0.1:8787/（端口被占用时自动顺延）。启动器依次尝试随包便携服务器（Go 编写，免安装）、Python 3、Windows 自带 PowerShell，只监听本机。不能直接双击 index.html 打开。
浏览器：Chrome / Edge 113 及以上（推荐），Firefox 115+、Safari 16.4+，需要支持 WebGL2 和 WebAssembly SIMD。
硬件：支持 WebGL2 的集成显卡即可，不需要独立显卡；内存 4GB 可运行，推荐 8GB；解压后约 130MB 磁盘空间。
网络：不需要联网。字体（SIL OFL 授权，已裁剪子集）、BGE-small-zh-v1.5 检索模型（MIT）、ONNX Runtime Web 推理引擎都已打包在本地。
源码构建：Node.js 18+，npm install → npm run build；技术栈为 Vite 5、TypeScript、three.js 0.170、Transformers.js 4.2。
