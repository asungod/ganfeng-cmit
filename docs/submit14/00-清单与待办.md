- 作答阈值 0.55：问展检索。低于阈值就拒答。标定集 n=101（61 条库内、40 条库外，分 dev / holdout，2026-10-08），见仓库 docs/calib/：
  - dev（用于选定阈值）：27/27 答对，库外 0/20 被误答。
  - holdout（选定后才跑）：召回 88.2%，精确率 78.9%，库外 4/20 被误答。误答的都是贴近主题的文化类问题，例如「滕王阁门票」「围屋还有人住吗」。
