## 七、许可写法

- 全文统一写「CC0 1.0」「CC BY 4.0」「SIL OFL 1.1」。界面署名原文保留「CC-BY」缩写，含义为 CC BY 4.0。
- CC0 1.0 不要求署名；本作仍在「关于本作品」和 `public/assets3d/credits.json` 中列出作者。
- CC BY 4.0 要求署名；音频署名见 `public/audio/opera/CREDITS.txt` 与界面「关于本作品」。
- 字体按 SIL OFL 1.1 随包分发，许可原文为 `public/fonts/OFL-*.txt`。
- MIT、Apache-2.0、BSD-3-Clause 为软件许可，完整文本在对应依赖包或 Go 发行版内。
