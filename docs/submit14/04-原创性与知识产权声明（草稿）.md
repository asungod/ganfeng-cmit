   - 本作品由本团队独立构思和完成，没有抄袭、剽窃、套作、冒名或虚假申报。

2. **原创部分**
   - 「瓷语 / 阁序 / 客家」三条参观线的内容组织与动线设计。
   - 约束表规则体系（合 / 勉 / 冲）与冲突改锁、可追溯回放交互。
