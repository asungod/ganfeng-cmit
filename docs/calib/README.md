| 阈值 | 作用 | 值 | 依据 |
|---|---|---|---|
| `PROTO_SCORE_THRESH` | 意图槽位：问句和约束表原型的余弦相似度，过了才写入约束（并且要领先第二名 ≥0.04） | 0.40 | `public/thresh-bench.json`：n=58 金标问，2026-09-04 实测；0.40 时召回 87.6%、精确 82.8% |

## 标定集 `qa-calib-set.json`
- 题库共 17 条：guide 4、瓷语 5、阁序 4、客家 4。
- 题库内改写问 61 条，每条标注可接受的题库原问。
- 题库外问 40 条。holdout 中有 10 条是同主题难例，比如「滕王阁门票多少钱」「青花瓷一件值多少钱」。
- **dev**（47 问）：第一轮用来选阈值。**holdout**（54 问）：选定 0.55 之后新写的，只用来检验，没有参与调参。
- 所有问句都是开发者自拟的，不是观众真实提问，也不是独立评测集。

## 跑法
离线包 dist 用 `python3 -m http.server` 起服务，headless Chrome 打开页面，执行 `calib_run.py`（通过 CDP 驱动 `window.__gfAgent.byVector` 和 `ask`）。原始输出见 `qa-calib-raw-2026-10-08.json`，分析用 `analyze.py`，结果见 `qa-calib-result-2026-10-08.json`。

## 结果（仅向量检索，阈值扫描节选）

| 阈值 | dev 召回 / 精确 | holdout 召回 / 精确 | holdout 题库外误答 | 全部 F1 |
|---|---|---|---|---|
| 0.500 | 100% / 87.1% | 88.2% / 69.8% | 9/20 | 0.844 |
| 0.525 | 100% / 93.1% | 88.2% / 73.2% | 7/20 | 0.870 |
| **0.550** | **100% / 100%** | **88.2% / 78.9%** | **4/20** | **0.905** |
| 0.575 | 100% / 100% | 82.4% / 82.4% | 4/20 | 0.902 |

| 0.625 | 88.9% / 100% | 76.5% / 92.9% | 1/20 | 0.885 |

- 召回 = 答到正确条目的题库内问 / 题库内问总数。精确 = 答到正确条目 / 所有作答（含题库外误答）。
- 0.55 是 dev 上最低的「零误答且全召回」阈值，在全部 101 问上 F1 也最高（0.905）。holdout 上 F1 最高的是 0.625（0.839），0.55 是 0.833，两者差距小于 0.01。
- **全流程**（向量 → 词面兜底 → 拒答），阈值 0.55：dev 27/27 答对，题库外 20/20 拒答；holdout 30/34 答对，题库外 16/20 拒答。
- 已知弱点：同主题、问法不同的题库外问题（门票、面积、价格、现在有没有人住）会被答成同主题的题库条目。这是纯检索方案的局限，界面上每个答案都附出处卡，观众能看出答的是哪一条。holdout 看过之后没有再调参，以免把检验集变成训练集。
